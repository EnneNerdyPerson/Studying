This website is made to supplement/mimic paid flashcard websites. Users can create flashcard sets and study them with multiple 
learning modes. Additional features include ability to create distinct user/password, edit already made sets, and more. This
website utilizes HTML, CSS, JavaScript, PHP, Node.js, and MySQL.

Requirements:
- MySQL
- Node.js
- PHP

How to start website locally:
1. In the command line, enter `php -S localhost:8000` to start php server/files
2. In the command line, enter `node server.js` to start Node.js server
3. Ensure that MySQL is running so that the database my be accessed
4. Open 'http://localhost:8000/login.html' in a browser to see the login page
